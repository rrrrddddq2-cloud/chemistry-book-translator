# 📚 موقع ترجمة الكتب الكيميائية
# Chemistry Book Translator Website

## 🎯 الهدف
موقع متخصص لترجمة الكتب الكيميائية من الإنجليزية إلى العربية بدقة عالية، مع قاموس شامل للمصطلحات الكيميائية.

## ✨ المميزات

### 1. 📋 قائمة المهام (To-Do List)
- إضافة وتعديل وحذف المهام
- حفظ تلقائي في Local Storage
- تصفية المهام (الكل، قيد الإنجاز، مكتملة)
- عرض الإحصائيات
- تصدير واستيراد المهام (JSON)

### 2. 📖 قاموس الكيمياء (Chemistry Dictionary)
- 6 كتب كيميائية متخصصة:
  - الكيمياء العامة
  - الكيمياء العضوية
  - الكيمياء التحليلية
  - الكيمياء الفيزيائية
  - الكيمياء غير العضوية
  - كيمياء البيئة
- مصطلحات مترجمة بدقة مع التعريفات
- بحث متقدم
- تصفية حسب اللغة
- نسخ المصطلحات
- طباعة وتصدير

### 3. 🌐 ترجمة فورية (Coming Soon)
- ترجمة نصوص كاملة
- الحفاظ على التنسيق
- معاينة الترجمة
